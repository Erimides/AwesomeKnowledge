# Librethoth
Colección en constante desarrollo de guías e información de util para el uso de varios tipos de Software.

## Que software cubrimos?
Intentamos priorizar software libre y preferentemente gratuito.

Estos son Nuestros estandares del software ideal para nuestra colección:

 - Gratuito
 - Codigo libre
 - Constante desarrollo
 - Respeto a la privacidad 
 
La mayoría de Software se encontrara en repositorios de codigo.


## Nuestro proposito

Ya existen decenas de indices sobre sitios web o apps gratis, como geniales colecciones Awesome en github o FMHY.NET que inspiraron este proyecto.
Lo que falta son guías, no solo saber lo que hay que usar si no ademas el como utilizarlo.

## Estructura.
En la carpeta indice podras encontrar herramientas recomendadas por categoría como en FMHY.net, solo que mucho mas selecto. En la carpeta guías se explicara como instalar por github por ejemplo, o como utilizar ciertas herramientas para las que se necesita algo más de conocimientos.
O para configuraciones y mucho más


## Descargo de responsabilidad y legales

- No nos hacemos responsables de ningun daño colateral traido por material encontrado, estas son solo recomendaciones. Aún que no nos haremos responsables lo tendremos en cuenta para el futuro (Por ejemplo si un sitio se volvio inseguro.)
- Intentaremos mantener la seguridad del usuario ante todo, aún así lamentablemente, ya que las herramientas estan fuera de nuestro control no podemos garantizarla en nombre de nadie
- Este proyecto es una mera compilación de datos, no distribuye material bajo Copyright ni pretende hacerlo. Recomendamos a los usuarios mantenerse bajo las leyes de su país, como terceros al no poder garantizarlo, no nos hacemos responsables de ninguna violación de Copyright que puedan ocasionar los datos aquí compartidos.
