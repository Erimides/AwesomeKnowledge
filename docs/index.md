# Librethoth
Colección en constante desarrollo de guías e información de util para el uso de varios tipos de Software.

## Que software cubrimos?
Intentamos priorizar software libre y preferentemente gratuito.

Estos son Nuestros estandares del software ideal para nuestra colección:

 - Gratuito
 - Codigo libre
 - Constante desarrollo
 - Respeto a la privacidad 
 
La mayoría de Software se encontrara en repositorios de codigo.


## Nuestro proposito

Ya existen decenas de indices sobre sitios web o apps gratis, como geniales colecciones Awesome en github o FMHY.NET que inspiraron este proyecto.
Lo que falta son guías, no solo saber lo que hay que usar si no ademas el como utilizarlo.
