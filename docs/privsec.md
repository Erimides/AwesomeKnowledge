# Los esenciales y mejores escudos para navegar en el internet.

## Bloqueadores de anuncios

**Generales**

- [uBlock Origin](https://github.com/gorhill/uBlock):ship::heart:/ [Adguard](https://github.com/AdguardTeam/AdguardBrowserExtension) / [uBO Lite]():material-information-outline:{ title="uBO Lite es mucho menos potente que uBO" } Bloqueadores de anuncios generales, se instalan como extensión del navegador
- [Zen](https://irbis.sh/zen/):desktop_computer: Bloqueador de anuncios general abarcativo a todo el sistema 
- [Sponsorblock](https://sponsor.ajay.app/):ship: Bloqueador de patrocinadores en videos. [Info de la comunidad](https://wiki.sponsor.ajay.app/w/Community).

**Spotify** :fontawesome-brands-spotify:

- [SpotX](https://github.com/SpotX-Official/SpotX)/[Linux/Mac](https://github.com/SpotX-Official/SpotX-Bash):desktop_computer: Bloqueador de anuncios para Spotify.
- [SpotSponsorblock](https://spotsponsorblock.org/):ship: Bloqueador de sponsors en los podcasts de Spotify.

**Twitch** :fontawesome-brands-twitch:

- [Adguard Extra](https://github.com/AdguardTeam/AdGuardExtra):ship: Extensión y/o insertador de scripts.
- [Script VAFT](https://github.com/ryanbr/TwitchAdSolutions#scripts):ship:

**Vallas de pago en diarios** :

- [Bypass paywalls clean](https://gitflic.ru/project/magnolia1234/bpc_uploads):heart::ship: extensión con montones de sitios compatibles para atravesar la valla de pago
- [Freedium](https://freedium-mirror.cfd/):ship: Sitio para saltarse las vallas de Medium
- [wallabag](https://wallabag.org/):desktop_computer: Self hosted



**Discord** :fontawesome-brands-discord:


- [Disblock Origin](https://codeberg.org/AllPurposeMat/Disblock-Origin) o [Discord-Adblock](https://codeberg.org/ridge/Discord-AdBlock) Esconden los anuncios sobre el nitro
