## Navegadores recomendados

Para navegar el internet con seguridad y privacidad uno necesita un navegador fiable, este sera su barco.

**Navegadores de escritorio recomendados**
 
 - [Librewolf](https://librewolf.net/) :heart:

 - [Brave](https://brave.com/download/)


**Navegadores para android recomendados**

  - [Cromite](https://github.com/uazo/cromite)

## Extensiones esenciales

Recomendamos las siguientes extensiones para navegador.
Estos pueden ser instalados desde el administrador de extensiones del respectivo navegador.

- [uBlock Origin](https://addons.mozilla.org/en-US/firefox/addon/ublock-origin/) El mejor bloqueador de anuncios web.
- ViolentMonkey [FF](https://addons.mozilla.org/en-US/firefox/addon/violentmonkey/) [Chrome](https://chromewebstore.google.com/detail/violentmonkey/ jinjaccalgkegednnccohejagnlnfdag?pli=1) con el siguiente [script](https://codeberg.org/gongchandang49/bypass-all-shortlinks-debloated) para sobrepasar redirecciones,  instalar script clickeando donde dice Install from Codeberg, seras redireccionado a violentmonkey donde debes instalar nuevamente.
